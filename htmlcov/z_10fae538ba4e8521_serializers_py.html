1"""REST API のレスポンスの形。 

2 

3drf-spectacular がここから OpenAPI スキーマ（``backend/openapi.json``）を作り、 

4frontend と拡張機能の orval がそのスキーマから TypeScript の型とクライアントを作る。 

5クラス名から ``Serializer`` を除いたものがスキーマ名（= TypeScript の型名）になる。 

6 

7``data`` / ``label`` は DRF の ``Serializer`` / ``Field`` が持つ属性と同名なので、 

8スタブ上は代入の型が合わない（実行時はメタクラスがフィールドとして取り出す）。 

9"""
